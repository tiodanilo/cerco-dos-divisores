# Cerco dos Divisores

Jogo para 2 a 4 jogadores sobre critérios de divisibilidade por 2, 3, 5, 9 e 10 (6º ano).

Acerte a pergunta, escolha um castelo adversário e dispare a catapulta. Errou? A pedra cai no seu próprio castelo. Vence o último castelo de pé.

Jogar: https://tiodanilo.github.io/cerco-dos-divisores/
